## Assumptions

| Assumption | Value | Source |
|---|---|---|
| Price | $49.00 per user per month | Business assumption |
| Contracts | 200 per user per month | Business assumption |
| Revenue per contract | $0.245 | $49 ÷ 200 |
| Calls per contract | 6 (1 summary + 5 follow-ups, one conversation) | Business assumption |
| Contract size | 16,299 tokens, in the system prompt | Measured (SAFE contract) |
| Summary request | 24 tokens | Measured |
| Follow-up question | 19 tokens each | Measured (Q1) |
| Follow-up answer | 41 output tokens each, all models | Measured on Haiku; assumed for Sonnet/Opus/Fable |
| Summary length (output) | Haiku 279, Sonnet 228, Opus 224, Fable 224 tokens | Measured, least-thinking runs |
| History | Every call resends the full conversation so far | How the API works |
| Caching | Contract written to cache on the summary call, read on all 5 follow-ups (within 5 minutes) | Prompt caching experiment |
| Gross margin | Revenue minus Claude API cost only (no hosting, support, etc.) | Simplification |
